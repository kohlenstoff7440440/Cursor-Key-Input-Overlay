## Installation

1. Download:

   `cursor_key_input_overlay-0.1.0-windows-x64.zip`

2. Close OBS Studio.

3. Extract the ZIP file into your OBS Studio installation directory.

For a standard OBS installation, the final DLL location should look like:

```text
obs-studio/
└── obs-plugins/
    └── 64bit/
        └── cursor_key_input_overlay.dll
```

4. Start OBS Studio.

5. Add a new source.

You should see:

* `Cursor Input Overlay`
* `Keyboard Input Overlay`
